# huncMarkovNCD 0.1.0

* First release: packaged from `model_ncd.R` and `model_parameters.R`.
* Deterministic and probabilistic (PSA) analysis of zelravine versus usual care; PSA reproduces the manufacturer's report for seed 2024.
* Year-1 valuation scenario (`scan_year1()`), CE plane, CEAC, frontier, ICER table and Markov trace plot.
* Interactive Shiny app (`launch_app()`), including a Toggles tab for the Time To Treatment Response switch.
* Manufacturer's report included in `inst/report/`.
